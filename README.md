# LSAT Crawl • Walk • Run

An ADHD-PI and aphantasia-friendly LSAT study system built around **accuracy → repeatability → speed**.

## Core method

Logical Reasoning uses **JOB → GIVEN → TARGET → GAP**:

- **JOB** — What am I being asked to do?
- **GIVEN** — What did the stimulus actually establish?
- **TARGET** — What must the correct answer accomplish?
- **GAP** — Where is the reasoning vulnerable or incomplete?

Two reset questions run through the app: **What is my job RIGHT NOW?** and **Where does it say that?**

## MVP tools

- Crawl / Walk / Run phase switcher
- Minimum viable one-question study session
- Interactive Argument Autopsy worksheet
- LR question-stem / JOB decoder
- Wrong-answer trap trainer
- Aphantasia-friendly RC verbal passage mapper
- Argumentative Writing preflight worksheet
- Mistake Detective + persistent local error log
- Autosaved working notes in browser local storage
- Responsive, keyboard-friendly, low-clutter interface
- Print stylesheet for worksheets

## Run locally

No build step or dependencies are required. Open `index.html` in a browser, or serve the directory with any static file server.

## Design principles

1. Externalize reasoning instead of relying on working memory or mental imagery.
2. One cognitive job at a time.
3. Accuracy before speed.
4. Small sessions count; reduce startup friction.
5. Interesting does not necessarily mean relevant.
6. Mistakes become reusable rules instead of judgments about ability.

## Roadmap

Next candidates include printable study-aid generators, conditional-logic translation tiles, richer progress analytics, timed practice modes, custom flashcards, RC viewpoint tracking, and import/export of the error log.
